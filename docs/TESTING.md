# 测试范围

本版在 Windows x64 本机使用 .NET SDK 10.0.403、运行时10.0.14验证，未在所有Windows版本或硬件上完成兼容性认证。

已执行：76条原音频实际解码与时长检查；文件清单一一对应；每角色100轮随机无轮内/跨轮连续重复；固定模式稳定；筛选更新、恢复、至少一句；完整配置往返与损坏/无效ID恢复；薄肌defaultOff默认八句。

发布版GUI自检：真实WPF窗口和音频设备静音快速重播40次、单输出、结束动画归位、停止释放；完整菜单项与筛选不关闭设置；Named Pipe真实连接、去重、hop和退出断开。

三个真实发布进程联调：薄肌起句播放次数（Sun/Feng/Shao）=2/1/1；峰哥起句=1/1/0；SunPet起句=1/0/0。检查root保留、hop0–3后终止，每种场景分别重复启动三个角色，重复实例退出，最终资源释放。

人工/界面自动化观察过三款透明头像、点击字幕和动画。峰哥筛选列表连续取消两项后保持打开，全部恢复；拖动保存已记录。GUI检查使用--ui-check临时显露任务栏按钮，普通启动仍隐藏。

未覆盖：独立Windows10设备、全部混合DPI/多显示器热拔插组合、扬声器声学录音、真实托盘点击退出的单独自动化回归。已实现对应窗口恢复与托盘事件，关闭释放通过自检。Windows版不支持Mac硬件摇晃或跨系统IPC。

`build.ps1` 在每个发布包上重新执行自检，记录在artifacts/test-results（不提交个人日志）。`integration-test.ps1` 可复现三角色链。首次v1.0.0-beta.1以预发布提供，欢迎提交可复现问题。
